The two bugs the ladder caught

Lazy-load spin deadlock

CUDA_MODULE_LOADING=LAZY enqueues first-launch module loads behind the never-exiting persistent spin kernels that eager and compress introduce; NVSHMEM 3.2.5 delivers every on-stream signal via a device kernel, so the producer can never load — circular wait.

Fix: ctor-time kernel preload + transport priming (1550b67, binary B). Caught because compress's first-ever GPU run was gated by the 2-node bring-up ladder.

Empty-expert split-cascade hang

set_barrier_ptr divides the full problem list by the non-empty problem count; any local expert with zero routed rows mis-buckets completions and the per-split barrier never fires. Hangs every layer1 arm — dense included — on any matrix with empty experts, i.e. all real-trace matrices at these shapes, at any node count.

Fix: c9b82b6 (binary C). Masqueraded as an “NN>2 bug” because synthetic bring-up matrices have no empty experts. Audit rule: when trace cells hang, bincount the routing first.
