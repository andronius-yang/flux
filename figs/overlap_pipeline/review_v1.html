Overlap Pipeline Draft

Token comm/comp overlap figure, 4 nodes: split-then-merge over the full dispatch and combine workflow. Draft v1 generated from measured 4n K2 b64 medians (capsule 20260905-141104). Lane: figs/overlap_pipeline/, brief in 00_brief.md.

The three answers the figure carries

1. From one NIC's point of view, the egress is one contiguous block. Every rank issues exactly three blocking puts per layer, one per remote node, back to back on one stream (measured inter-put gap ≤ 0.01 ms on 16/16 ranks). Split cuts each node's outbound stream into four equal chunks, so GPU0 and GPU1 of the same node carry the same length regardless of whose tokens they are (shifted traffic, the hatched pull). Merge sets the block's length: one wire row per (token, destination node) instead of one per top-k copy (removed traffic). The bubbles that remain are the plan bracket before the first put and the post-GEMM barrier, not NIC idle.
2. A window releases a row-slice of every local expert, not an expert. A window is chunk g of the (source node → my node) stream, delivered by gateway g over NVLink. Because the GEMM's A order is lane-monotone inside each expert, each window owns a contiguous M-slice of every local expert's problem, and its arrival flips one signal slot that the tiles covering those rows spin on. Own-node rows arrive first, so the GEMM starts 0.2 ms after the first put and the gate ticks (own, N1, N2, N3) walk across it; the last window lands about 1.5 ms before the GEMM ends.
3. Combine is the mirror with one new compute stage. The layer-1 GEMM is split into destination-node waves (own node last), a wave's completion counter releases a converge over NVLink to the same-rank peer (gateway on the sender side), and a resident side-stream kernel, Σ pre-reduce (6 CTAs), sums the node's partials into one row per (token, source node) before one blocking put per remote node lands straight in the home rank. Dispatch merges by identity (a pack); combine partials are numerically distinct, so bytes are proportional to contributions unless summed before the NIC. Measured: first put at wave 0 + 4.6 ms; raising Σ to 48 CTAs cuts that to 1.2 ms and costs the GEMM +3 ms.

Format for NSDI

Recommendation: cross-column (figure*), the two sub-figures stacked, about 7.0 in × 2.9 in. Each row keeps a 2.2 in topology panel and a 4.6 in timeline; at that width 25 ms maps to ≈0.18 in/ms, so a 3.4 ms put is 0.6 in and the gate labels stay at 6–7 pt. In a single column (3.33 in) the timeline drops to ≈2.3 in for the same span, puts become 0.3 in, the eight rows per sub-figure need 0.11 in pitch, and the topology panel has to go; that only works if the figure is split into two single-column figures placed in the dispatch and combine subsections, each without the topology (reusing sp_mg_v3 and the system overview for that).
