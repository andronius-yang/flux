Method

  1. Arms. OURS = ours_l01_s1_pv2_r2; COMET = l01_allgather_dense (this repo’s fused allgather l0 + dense-ring l1); ring = l01_nvshmem (blocking-put ring, unfused GEMM). All cells: isolated mode, 10 iters / 5 warmup, FLUX_TEST_DETERMINISTIC=0, Kimi-K2 shape on captured routing (livecodebench/execution, layer 5), budgets are the strict per-rank pre-topk send budget.
  2. COMET at 128 ranks. Out of the box it does not run at 32n: upstream Flux’s dense-dispatch sort kernel keeps a static 64-source-rank shared-memory table (MaxTpRanks=64, unguarded), which overflows into the expert prefix sums at W=128 — illegal memory access on some ranks, wedge on the rest (capsule 20260901-075429…04875008). Raising the table to 128 (+ a loud guard) makes it run: capsule 20260902-235755 is the source of every 32n COMET point. Its b64 cell does not fit a 40 GB A100, bracketed by three probes: heap 15G and 17G → NVSHMEM_MALLOC failed (capsules 20260902-235755, 20260903-023656); heap 24G → torch OOM needing 16.1 GiB (an 8 GiB copy of the dense gathered buffer on top of 8.1 GiB resident) beside ~6.1 GiB non-torch overhead (20260903-014242). The dense all-gather holds W×tokens/rank twice; no heap value satisfies both sides, so the b64 line ends at 16n. FAST is excluded beyond 16 servers (documented 16-server limit, handoff 24).
  3. Binary identity. 32n cells run the W≤128 binary (three 32n cap fixes: l1 node cap, l0 owner bitmask, l0 stage-1 smem window — all statically inert at W≤64); 4/8/16n cells are the handoff-30 / 8-31 capsules on the pre-fix tree. A 4n re-run on the patched binary reproduced the handoff-30 OURS row within ±3.6% (capsule 20260901-021249), bounding the cross-build error at well below every plotted effect.
  4. Capsules. OURS 32n: 20260901-024555; COMET 32n: 20260902-235755; ring 32n: 20260901-075429…5433d58e; 2n head-to-heads (each baseline + OURS in ONE capsule, W≤128 binary): COMET 20260901-101958, ring 20260904-004243; 4/8/16n: handoff-30 tidy dataset + the 8/31 ring ladder (20260831-051230/052029/063232). Ring b8 exists only at 2n and 32n and is omitted from the ring panel. OURS 2n totals in the two capsules agree within ±1.5%.
