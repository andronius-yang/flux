# figs/weak_scaling/h100/data — routing data for the H100/ALPS weak-scaling lane

Present ONLY on the `h100-weak-scaling` branch (never merge this directory into main).
Authority for what to do with it: `docs/handoff/35_h100_alps_weak_scaling.md` §4.1.

| file | what |
|---|---|
| `traces_k2_lcb_execution.tar.xz.part-00..02` | the Kimi-K2-Thinking `livecodebench/execution` expert-selection pool (479 trace JSONs + `pool.manifest.json` + `pool_cache/`), tar → xz → split into sub-50 MiB parts (GitHub's 100 MiB per-file limit). Raw 1.53 GB. |
| `matrices_k2_weak.tar.xz` | the 10 pre-generated traffic-matrix sets (W = 8/16/32/64/128 × 1/64 MiB) with their `.meta.json`, `.routing.txt`, `.oracle_load.json`, `.oracle_routing.txt` sidecars — bit-identical ids to the A100 campaign |
| `SHA256SUMS.txt` | checksums of the files here + of the reassembled `.tar.xz` and `.tar` streams |

Unpack (from the clone root; produces the gitignored `traces/` and `matrices/` next to this directory):

```bash
cd figs/weak_scaling/h100
(cd data && sha256sum -c SHA256SUMS.txt)
mkdir -p traces/moonshotai/Kimi-K2-Thinking/livecodebench
cat data/traces_k2_lcb_execution.tar.xz.part-* | xz -dc | tar -x -C traces/moonshotai/Kimi-K2-Thinking/livecodebench
tar -xJf data/matrices_k2_weak.tar.xz -C .
ls traces/moonshotai/Kimi-K2-Thinking/livecodebench/execution | wc -l   # 481
ls matrices | wc -l                                                     # 50
```

Provenance: pool fetched by `sweeps/fetch_traces.py` (HF dataset
`core12345/MoE_expert_selection_trace`, model prefix `moonshotai/Kimi-K2-Thinking`);
matrices generated by the sweep runner on Perlmutter (see the capsules cited in
`figs/weak_scaling/figure_src.md`). Packed 2026-09-06/07 on Perlmutter.
