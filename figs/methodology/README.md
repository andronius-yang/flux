# Methodology figures — lane index (opened 2026-09-05)

Home of the figures for the **methodology subsection**: one diagram per
mechanism, explaining each optimization in depth (the system-overview
figure in `figs/system_overview` only names them and says when/where
they act). Discussions, key insights and specs live here, following the
lane conventions of `figs/main_perf`, `figs/ablation_cycling`,
`figs/motivation` and `figs/system_overview`: every aesthetic value is a
`[knob]`, rulings are dated, revisions never-mix, and data/mechanism
claims cite the capsule, handoff or source file they come from.

Mechanism names are the ablation legend vocabulary (`figs/ablation_cycling`
REV 0.3), verbatim: "token comm comp overlap", "expert placement &
routing", "expert-dispatch overlap". One vocabulary across the paper.
